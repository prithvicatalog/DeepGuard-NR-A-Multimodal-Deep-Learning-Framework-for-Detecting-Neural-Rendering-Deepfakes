# DeepGuard-NR-A-Multimodal-Deep-Learning-Framework-for-Detecting-Neural-Rendering-Deepfakes
DeepGuard-NR is an explainable, multi-branch forensic system for detecting videos generated or manipulated through neural rendering pipelines — Neural Radiance Fields (NeRF) and 3D Gaussian Splatting (3DGS) — as well as conventional facial deepfakes.
